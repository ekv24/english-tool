# English Tool

English Tool помогает читать технические материалы на английском и расширять словарный запас на уровне B2. Начни с [требований к читалке](docs/specs/reading-vocabulary.md). Материалы для чтения подготавливает Codex. При подготовке сохраняй оригинал.

## Agent skills

- Требования, вопросы и задачи веди по [правилам трекера](docs/agents/issue-tracker.md).
- При разборе задач используй [метки triage](docs/agents/triage-labels.md).
- Перед исследованием или изменением предметной области прочитай [правила словаря и решений](docs/agents/domain.md).
