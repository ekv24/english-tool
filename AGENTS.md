# English Tool

English Tool помогает читать технические материалы на английском и расширять словарный запас на уровне B2. Начни с [требований к читалке](docs/specs/reading-vocabulary.md). Материалы для чтения подготавливает Codex. При подготовке сохраняй оригинал.

Читалка также служит оболочкой личной системы рекомендаций: [требования](docs/specs/reading-recommendations.md), [процедуры агентов](docs/agents/recommendations.md).

## Agent skills

- Требования, вопросы и задачи веди по [правилам трекера](docs/agents/issue-tracker.md).
- При разборе задач используй [метки triage](docs/agents/triage-labels.md).
- Перед исследованием или изменением предметной области прочитай [правила словаря и решений](docs/agents/domain.md).

## Журнал интересов

- Если пользователь в чате делится впечатлением о прочитанном, задаёт вопрос по тексту или говорит, о чём хочет читать, запиши это: `npm run interests -- note "<суть его словами>" --material <id> --kind feedback|question|interest|note`. Затем сообщи одной строкой, что записано. Подробности — в скилле `log-reading-feedback`.
- На вопрос «что почитать» и на просьбу найти материалы сначала прочитай `npm run interests -- digest`, затем действуй по скиллу `recommend-reading`.
- Команды по умолчанию работают с живой читалкой на `127.0.0.1:4173`. Для проверок подними отдельный сервер с копией базы и передай `--server`.
- Дайджест, профиль и журнал — личные данные. Репозиторий публичный: не коммить их и не вставляй в issues.
