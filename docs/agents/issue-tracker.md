# Локальный трекер

- Спецификация функции хранится в `docs/specs/<feature>.md`. Требования меняются после согласования с пользователем. Спецификация ссылается на карточки реализации.
- Технические задачи хранятся по одной на файл в `.scratch/<feature>/issues/<NN>-<slug>.md`. Номер начинается с `01` и служит идентификатором внутри функции.
- Карточка содержит ссылку на требования, критерии приёмки, `Blocked by`, `Status` и `Assignee`. Обсуждение дополняй в разделе `## Comments`.
- Пользователь утверждает продуктовые требования и решения. Исполнитель ведёт назначенную ему карточку, а открытый вопрос, требующий выбора пользователя, направляет ему на согласование.

## Работа с технической задачей

1. Открой карточку по пути или номеру внутри функции. Если задача не указана, выбери открытую незанятую карточку с согласованными критериями и выполненными зависимостями. Метка `ready-for-agent` описывает результат разбора карточки. Готовность к исполнению проверь по критериям и зависимостям.
2. Перед началом перечитай карточку, укажи исполнителя в `Assignee` и установи `Status: claimed`.
3. Проверь критерии приёмки и зафиксируй результат со ссылкой на проверяемую работу. Установи `Status: resolved`. Для отменённой карточки используй `Status: cancelled` и укажи причину. Зависимость считается выполненной, когда её требуемый результат доступен. При отмене зависимости согласуй её снятие или замену.

## Wayfinder

- Карта работы хранится в `.scratch/<effort>/map.md`. В `Destination` запиши ожидаемый результат, в `Notes` — условия и допущения, в `Decisions so far` — ссылки на принятые решения, в `Not yet specified` — темы, по которым ещё рано заводить карточки, в `Out of scope` — исключения и основания. По умолчанию карта ведёт вопросы до принятия решений. Если пользователь поручил и исполнение через карту, отрази это в `Notes`.
- Карточки карты хранятся в `.scratch/<effort>/issues/<NN>-<slug>.md`. Нумерация общая для одного `<effort>`. `Type` принимает `research`, `prototype`, `grilling` или `task`. Вопросы используют `Status` и `Assignee`.
- В `Blocked by` укажи номера зависимостей внутри карты. Список доступных вопросов состоит из открытых незанятых карточек, чьи зависимости дали требуемый результат. Если пользователь указал вопрос, начни с него при выполненных зависимостях. Иначе возьми первый доступный по номеру. До работы запиши исполнителя и `Status: claimed`.
- Для закрытия запиши результат и доказательства под `## Answer` либо дай там ссылку на место, где хранится ответ. Поставь `Status: resolved` и добавь краткую ссылку в `Decisions so far`. При отмене вопроса за пределами `Destination` укажи `Status: cancelled`, причину и ссылку в `Out of scope`. Отменённые зависимости пересмотри явно, остальные открытые вопросы сохрани.
