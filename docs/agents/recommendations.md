# Журнал интересов и подбор материалов

Требования описаны в [спецификации](../specs/reading-recommendations.md), термины — в [словаре](../../GLOSSARY.md). Все команды обращаются к запущенной читалке, по умолчанию к рабочей на `http://127.0.0.1:4173`. Для опытов и тестов подними отдельный сервер с копией базы и передавай `--server <url>`.

Вывод команд содержит личные данные. Не сохраняй его в репозиторий, в issues или в коммиты.

## Записать сказанное в чате

Записывай, когда пользователь:

- делится впечатлением о материале: понравилось, скучно, трудно, хочется продолжения;
- задаёт вопрос по тексту, который читает;
- говорит, о чём хочет или не хочет читать.

```sh
npm run interests -- note "<суть его словами>" --material <id> --kind feedback
npm run interests -- note "<вопрос>" --material <book>/<slug> --kind question
npm run interests -- note "<интерес>" --kind interest
```

- `--material` — `id` статьи или книги, а для вопроса по главе — `<book>/<slug>`. Если `id` неизвестен, найди его в начале `npm run interests -- digest`.
- Пиши кратко, на языке пользователя, без своих оценок. Одна мысль — одна запись.
- После записи сообщи одной строкой, что записано. Если пользователь просит удалить запись, выполни `npm run interests -- forget note:<id>`.
- Отзыв, который читатель оставил в **Your take**, уже записан. Повторять его не нужно.

## Подбор материалов

Подбор выполняется по просьбе («что почитать», «найди статьи про…»).

1. **Дайджест.** Выполни `npm run interests -- digest`. Посмотри, что дочитано, где **More like this** и **Not for me**, где английский был трудным, какие слова сохранены, что сказано в журнале и что уже было предложено.
2. **Профиль.** Обнови профиль: `npm run interests -- profile` выводит текущий, `npm run interests -- profile --set <файл>` сохраняет новый. Профиль занимает до страницы и включает:
   - темы и вопросы, которые увлекают, с примерами материалов;
   - авторов, издания и форматы, которые нравятся, и чего избегать;
   - уровень английского: где было **Just right** и **Hard**, сколько поисков на 1000 слов;
   - предпочтительную длину и время чтения.

   Файл профиля держи вне репозитория (например, во временном каталоге).
3. **Кандидаты.** Начни с источников и авторов материалов с отметкой **More like this**, затем ищи по темам профиля. Одно место из пяти отдай теме за его пределами. Не предлагай то, что уже есть в библиотеке или было скрыто (`dismissed`). Для статьи проверь, что текст открыт. Для книги укажи издание, файл понадобится от пользователя.
4. **Оценка.** `score` — вероятность, что читатель ответит **More like this** (0–1). Учитывай совпадение с темами, трудность английского для уровня B2 и длину. Оценки выше 0.8 оставляй для очевидных попаданий.
5. **Предложения.** Добавь не больше пяти за раз:

   ```sh
   npm run interests -- suggest --title "<название>" --url <ссылка> --kind article|book \
     --why "<одно-два предложения, связанные с сигналами>" --score 0.7 \
     --publisher "<издание>" --minutes 20 --level right
   ```

   `--author` используется для книг, `--level` (easy, right, hard) — твоя оценка английского. `why` пиши для читателя, по-английски, как подпись в интерфейсе: «You finished X and saved terms about Y».
6. Коротко перечисли пользователю, что добавил и почему. Предложения появятся в **For you** на главной странице.

## Подготовить выбранное

Отметку **Want to read** видно в дайджесте как `[want]`. Подготовь материал навыком [prepare-english-tool-material](../../.agents/skills/prepare-english-tool-material/SKILL.md), затем свяжи предложение с материалом:

```sh
npm run interests -- imported <suggestion-id> <material-id>
```

После этого карточка уходит из **For you**, а материал появляется на полке.

## Оценка подбора

Когда наберётся 15–20 предложений, сравни `score` с исходом. Посмотри, сколько предложений получили **Want to read**, были дочитаны и получили **More like this**. Вывод запиши в профиль и в карточку [№06](../../.scratch/reading-recommendations/issues/06-evaluate-recommendations.md) без личных подробностей.
