# Озвучка словаря (Listen)

В Vocabulary есть плеер **Listen**: английское слово, пауза 4 секунды, перевод, слово и перевод ещё раз, пауза 3 секунды. Запись играет по кругу, пока её не остановят.

## Что звучит

Набор на день выбирает сервер (`dayPlaylist` в `vocabulary-review.mjs`), до 60 выражений. Это полчаса, в которые каждое выражение проходит дважды. В него входят только выражения с [проверенным переводом](vocabulary-check.md), которые не исключены из повторения.

- Шанс попасть в набор падает с числом разных дней, когда слово звучало: до 7 дней — 100%, 7–13 — 50%, 14–20 — 25%, дальше 10%.
- Интервал карточки тоже снижает шанс: 3 дня — 33%, 7 дней — 14%. Ниже 10% шанс не опускается.
- **Again** начинает счёт дней заново. Отмечать слова в плеере нельзя, это решение пользователя.
- Свободные места занимают новые выражения в том же порядке, что в карточках. Непрослушанные остаются на завтра.

День засчитывается, если слово и перевод прозвучали. Плеер копит услышанное на устройстве и отправляет при связи.

## Как делается запись

`scripts/vocabulary-audio.mjs` запрашивает набор и запускает `scripts/vocabulary-audio.py`. Тот озвучивает новые слова, собирает один MP3 примерно на полчаса (порядок в каждом круге новый) и пишет `mix.json`. Один файл нужен потому, что Safari на заблокированном iPhone ненадёжно переключает записи. Плеер сначала скачивает файл целиком, поэтому играет и без сети.

- **Английский** — Kokoro, голос Heart, по словарным транскрипциям. Одинаковое написание (record, use) различается по переводу и предложению. Слов вне словаря касается eSpeak.
- **Русский** — Qwen3-TTS с созданным голосом `voice.wav`. Модель импровизирует, поэтому каждую запись слушает Whisper. Ударения так не проверяются.

Всё лежит в `speech/` каталога данных: окружение, модели, голос, готовые слова (`clips/`) и запись. Ежедневному запуску сеть не нужна. Паузы, темп и голоса заданы константами в начале Python-скрипта. После их изменения запись пересобирает `npm run vocabulary-audio -- --force`.

## Установка (Mac с Apple Silicon)

```sh
cd <каталог данных>/speech
uv venv --python 3.12 venv
uv pip install --python venv/bin/python -r <репозиторий>/scripts/vocabulary-audio-requirements.txt
venv/bin/python <репозиторий>/scripts/vocabulary-audio.py . --design-voice          # русский голос, один раз
echo '{"cards":[{"key":"","lemma":"hello","text":"hello","translation":"привет","sentence":""}]}' |
  venv/bin/python <репозиторий>/scripts/vocabulary-audio.py . --download            # скачать модели
npm run vocabulary-audio                                                            # запись на сегодня
```

Модели занимают около 5 ГБ. Без `mix.json` плеер не показывается.

На рабочем Mac запись обновляет та же задача launchd, что и проверка переводов (`local.english-tool.check-vocabulary`, 7:00), сразу после неё. Журнал общий.
