# Метки triage

В технической карточке указывай категорию `Category: bug` или `Category: enhancement` и одну метку `Triage` из таблицы. Ход исполнения отражай в `Status`. Для вопросов Wayfinder используй их собственные состояния.

| Метка | Значение |
| --- | --- |
| `needs-triage` | Нужен первичный разбор. |
| `needs-info` | Для разбора нужны сведения от автора или пользователя. |
| `ready-for-agent` | Условия задачи описаны, реализацию можно поручить агенту. |
| `ready-for-human` | Реализация требует участия человека. |
| `wontfix` | Принято решение оставить поведение как есть. |
