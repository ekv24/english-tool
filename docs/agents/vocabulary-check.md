# Проверка переводов словаря

Машинный перевод при сохранении слова часто не учитывает предложение. Раз в день скрипт `scripts/check-vocabulary.mjs` отдаёт Codex новые сохранённые выражения и записывает исправления в живую читалку.

- **Что проверяется.** Выражения без отметки о проверке. Codex видит текст, базовую форму, текущий перевод, предложение и название материала. Он возвращает словарную форму и перевод в значении из предложения.
- **Правки читателя.** Если перевод меняли после сохранения, скрипт его не трогает и уточняет только базовую форму.
- **История.** Ключ записи включает перевод, поэтому исправление заменяет запись. Срок повторения и выбор читателя переходят к новой записи в той же транзакции. Прежний перевод хранится в таблице `vocabulary_checks`.
- **Безопасность.** Предложения взяты из чужих текстов. Codex работает без инструментов, в песочнице только для чтения и в пустом временном каталоге. Записывает скрипт после проверки формата ответа.

```sh
npm run check-vocabulary -- --dry-run          # показать исправления
npm run check-vocabulary                       # исправить в читалке на 127.0.0.1:4173
npm run check-vocabulary -- --server <url>     # для опытов на копии базы
```

Модель задаёт `--model` или `ENGLISH_TOOL_CHECK_MODEL`, путь к Codex — `ENGLISH_TOOL_CODEX`. Codex использует вход в ChatGPT на этом компьютере. Если проверка не удалась, выражения останутся непроверенными до следующего запуска.

На рабочем Mac задачу запускает launchd, `local.english-tool.check-vocabulary`, каждый день в 7:00. Журнал исправлений — `.local/check-vocabulary.log` в каталоге рабочей копии. В журнале личные данные, в репозиторий его не копируй.
