# Как читать англоязычные статьи с переводом

Проверено 14 ноября 2026 года по исходникам и документации. В проверяемом сценарии Codex готовит статью в локальном HTML, а читалка сразу показывает перевод выделенного английского слова или фразы. По запросу она объясняет смысл в контексте. Читалка сохраняет позицию и предлагает задания по содержанию или лексике.

## Какой вариант подходит

- Если важен именно **локальный HTML с исходной структурой статьи**, достаточно браузерной читалки на постоянном адресе `localhost` и навыка Codex для подготовки статей. Chrome на компьютере умеет переводить текст локально после загрузки языковых моделей. В документации есть английский и русский, а доступность пары проверяется через `Translator.availability()`. Для отдельных трудных мест Codex может подготовить объяснения и задания одновременно с HTML. [Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api?authuser=447), [W3C Selection API](https://www.w3.org/TR/selection-api/), [Навыки OpenAI](https://developers.openai.com/plugins/concepts/skills).
- Если достаточно **читать текст внутри готовой локальной читалки**, первым стоит проверить Glosano. Он уже умеет EN → RU, принимает Markdown и текст, хранит библиотеку и прогресс на собственном сервере и проводит интервальное повторение. На macOS запускается через Docker. [Glosano README](https://github.com/Glosano/glosano/blob/75a7a7cb0a65072b16bb9815f5edeaf2834cfb90/README.md#features), [Настройка EN → RU](https://github.com/Glosano/glosano/blob/75a7a7cb0a65072b16bb9815f5edeaf2834cfb90/docs/self-hosting.md#L249-L263).
- Если для **проверки самого способа чтения** подходит облачный сервис, Readlang уже сочетает перевод, пояснения на русском, библиотеку, позицию и повторение слов. [Readlang Features](https://readlang.com/features), [Пояснения на русском](https://forum.readlang.com/t/feature-request-explain-section-in-secondary-language-not-target-or-native/2216/5), [Позиция в тексте](https://forum.readlang.com/t/page-numbers-instead-of-percentage/4843/2).

## Что даёт форк Learn Harness

Речь, вероятно, о публичном [dimayip/learn-harness](https://github.com/dimayip/learn-harness), который совпадает по названию и квизам. В [демо автора](https://learn-harness.vercel.app/) это курс по Harness Engineering. Проверенный коммит — [`f6fffab`](https://github.com/dimayip/learn-harness/commit/f6fffab46d73a95692ee678cc4bead028430073f).

- HTML, CSS и JS без фреймворка. Данные 25 понятий лежат в `WordRoots`. На карточке есть готовый вопрос с одним правильным вариантом, мгновенная обратная связь и отметка об освоении. Есть индекс понятий, флешкарты и сводка по результатам. [README](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/README.md#L11-L28), [Данные урока](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/js/wordData.js#L1-L33), [Проверка ответов](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/learn.html#L167-L212).
- Состояние хранится в `localStorage` и переносится вручную через JSON. Страница продолжает с последней карточки, а переход к следующей прокручивает страницу к началу. Service Worker кэширует статические ресурсы сайта. [Хранилище](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/js/storage.js#L67-L139), [Позиция карточки](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/learn.html#L105-L133), [Навигация](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/learn.html#L214-L226), [Кэшируемые ресурсы](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/sw.js#L1-L32).
- Для читалки потребуются импорт статей, выбор слова или фразы в документе, перевод, пояснение, библиотека статей и позиция внутри каждой статьи. Квиз можно взять за образец для понимания прочитанного. Его данные и результаты привязаны к идентификатору понятия, а флешкарты перебирают те же понятия. При адаптации также понадобится безопасный рендеринг импортированного содержимого, поскольку детали урока подставляют заранее написанные строки через `innerHTML`. [Карточка понятия](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/root-detail.html#L103-L145), [Квиз и хранение попыток](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/js/storage.js#L91-L116).
- Публичный репозиторий технически можно форкнуть на GitHub. Автор указал MIT в README. Отдельного файла `LICENSE` в дереве нет. При переносе кода стоит сохранить указание авторства и лицензии и уточнить у автора полный текст уведомления, если планируется распространять производную версию. [Декларация MIT](https://github.com/dimayip/learn-harness/blob/f6fffab46d73a95692ee678cc4bead028430073f/README.md#L82-L84), [GitHub о форках и лицензиях](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository#determining-the-location-of-your-license), [Текст MIT](https://opensource.org/license/mit).

По коду проекта форк экономит работу над квизом и экраном прогресса по курсу. Основной сценарий чтения всё равно понадобится проектировать и проверять на статье.

## Где запускать свою читалку

- **Браузер и Codex.** Навык может готовить локальную статью, словарь важных выражений и задания. В самой читалке Selection API даёт выбранную строку, быстрый перевод идёт через готовый словарь или браузерный переводчик, а позицию можно сохранять по ID статьи и абзаца. Постоянный адрес `localhost` позволяет библиотеке и статьям пользоваться одним браузерным хранилищем. Для пояснений к произвольному выделению можно позже проверить локальное подключение через `codex exec` или Codex App Server. Пригодность по времени ответа нужно измерить. Плагин имеет смысл для установки и распространения навыка или при добавлении MCP-инструментов. [Selection API](https://www.w3.org/TR/selection-api/), [Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html#the-localstorage-getter), [Codex CLI](https://learn.chatgpt.com/docs/non-interactive-mode), [Codex App Server](https://learn.chatgpt.com/docs/app-server#authentication), [Архитектура плагинов](https://developers.openai.com/plugins/concepts/plugins).
- **Окно macOS.** Для иконки и отдельного окна Safari поддерживает «Добавить в Dock» начиная с macOS Sonoma. Такое окно хранит данные отдельно от обычного Safari. Если выбран встроенный переводчик Chrome, поддержку в Safari следует проверять отдельно. Полноценное нативное приложение имело бы смысл при потребности в системных функциях, например в открытии HTML из Finder или системной команде перевода за пределами читалки. [Safari Web Apps](https://support.apple.com/en-us/104996), [Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api?authuser=447).
- **Telegram Mini App.** Это веб-приложение внутри Telegram. Для обычного запуска бот указывает HTTPS-адрес, доступный с телефона. Локальные файлы и `localhost` на Mac сами по себе на телефоне недоступны. Общая библиотека потребует доступного хранилища, а при серверной авторизации через Telegram потребуется проверять `initData`. Перенос интерфейса оставляет отдельным вопросом провайдера перевода для мобильного WebView. OpenAI допускает продолжение использования метода аутентификации App Server в локальных приложениях и отдельно указывает, что он не разрешён для hosted-сервисов. [Telegram Bot API](https://core.telegram.org/bots/api#webappinfo), [Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app), [Codex App Server](https://learn.chatgpt.com/docs/app-server#authentication).
- **Claude, если подразумевались Claude Artifacts.** Бесплатный план позволяет сделать интерактивный артефакт. Встроенное сохранение данных между сессиями доступно на платных планах. Для данного сценария Codex уже может подготовить HTML, глоссарий и задания. Статья на сайте Anthropic не требует использования Claude как провайдера. [Доступность Claude Artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them), [Запуск Codex](https://learn.chatgpt.com/docs/non-interactive-mode).
- **Облачный хостинг, если речь о нём.** Та же читалка может открываться в мобильном браузере по HTTPS. Для общей позиции и словаря потребуется хранить состояние на сервере или в другом синхронизируемом хранилище. Браузерный `localStorage` сам по себе хранит состояние на стороне клиента. [Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html#introduction).

Проверка ограничилась опубликованным кодом и документацией. Установка, локальная совместимость браузерных расширений, скорость и качество технического перевода, восстановление позиции на конкретной статье и доступность языковой модели в браузере пользователя остались без проверки.
