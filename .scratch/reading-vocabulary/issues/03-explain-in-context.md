## Что должно работать

Из подсказки с переводом читатель может отдельно открыть пояснение к слову или фразе в данном предложении.

## Критерии приёмки

- [ ] Пояснение учитывает предложение и смысл выражения в техническом контексте.
- [x] Короткий перевод доступен сразу, пояснение открывается отдельным действием.
- [x] После закрытия подсказки виден тот же абзац.

## Comments

В Chromium проверены краткий перевод, отдельное раскрытие пояснения и сохранение позиции при закрытии. В словаре есть проверенные пояснения для ключевых выражений первой статьи.

Для произвольного выделения без словарной статьи доступен перевод содержащего его предложения. Объяснение значения самого выделения в произвольном контексте остаётся открытым.
