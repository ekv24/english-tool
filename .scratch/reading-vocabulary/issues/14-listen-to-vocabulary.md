# 14 — Слушать слова по кругу

[Требования к читалке](../../../docs/specs/reading-vocabulary.md), [устройство](../../../docs/agents/vocabulary-audio.md).

Пользователь хочет включить в Vocabulary запись и идти на работу: слово, пауза,
перевод, по кругу. Только слова, которые ещё не выучены; выученные звучат всё реже.
Голос женский, произношение правильное. Решения 24 ноября 2026 года: первый формат
из образцов, голоса Heart и Anna, отмечать слова в плеере не нужно.

- [x] Набор на день с падающей частотой.
- [x] Озвучка слов и переводов, проверка распознаванием, одна запись на 28 минут.
- [x] Плеер: повтор по кругу, слово и перевод на экране, работа без сети.
- [x] Ежедневное обновление после проверки переводов.
- [x] Набор на полчаса: до 60 слов вместо 20–40, решение пользователя 25 ноября 2026 года.
- [x] Темп спокойнее: пользователь не успевал вспомнить. Пауза на припоминание 4 с, второй перевод, паузы между карточками 3 с.
- [ ] Запись играет на iPhone пользователя с заблокированным экраном.
